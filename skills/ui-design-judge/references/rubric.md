# Default visual rubric

Use the product's established goals and interaction model. Assess task performance through visible evidence, not resemblance to a fashionable template.

| Category | What to examine |
| --- | --- |
| hierarchy | Primary action, current context, content order, status and metadata prominence |
| typography | Readable body/code text, size relationships, line length, truncation and wrapping |
| density | Scanability, grouping, whitespace serving the task, useful information retained |
| color_contrast | Readability in each theme, meaningful status color, visible focus/selection where shown |
| consistency | Spacing, radii, borders, icons, naming and controls across the supplied surfaces |
| affordance | Discoverability and clarity of controls, active state, disabled/error/loading presentation |

Score each required scenario separately. A wide desktop screenshot cannot stand in for a narrow layout or a theme not shown.

- 0–3: task or reading is substantially obstructed.
- 4–6: usable pieces, significant visible problems.
- 7–8: coherent and useful, with identifiable improvements remaining.
- 9: near-release quality; only minor visible refinements remain.
- 10: no meaningful visible improvement within this scope and evidence.

Fractions are permitted but do not imply measurement precision. Explain the visible reason for a rating. If evidence does not support a rating, use null and state what is missing. An overall summary is optional and never replaces scenario/category scores.
